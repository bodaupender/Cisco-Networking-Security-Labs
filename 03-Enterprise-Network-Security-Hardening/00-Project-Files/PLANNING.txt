| Phase  | Configuration                | Main purpose                                          |
| ------ | ---------------------------- | ----------------------------------------------------- |
| **1**  | Device basic configuration   | Hostnames and clean baseline                          |

| **2**  | VLAN configuration           | Separate departments/security zones                   |

| **3**  | IP addressing / SVI          | Give VLANs their gateways and management addressing   |

| **4**  | Port assignment              | Put department devices into the correct VLANs         |

| **5**  | Trunking                     | Carry required VLANs between network devices          |

| **6**  | EDGE-R1 routing              | Connect the internal network to the edge/ISP          |

| **7**  | DHCP                         | Automatically assign IP addresses to endpoints        |

| **8**  | DHCP Snooping                | Prevent rogue DHCP servers                            |

| **9**  | Dynamic ARP Inspection (DAI) | Protect against ARP spoofing                          |

| **10** | STP Security                 | PortFast + BPDU Guard and STP protection              |

| **11** | Port Security                | Restrict unauthorized devices on access ports         |

| **12** | Unused-port hardening        | Shutdown unused interfaces and place them in VLAN 999 |

| **13** | Connectivity verification    | DHCP, VLAN, inter-VLAN, router and Internet/ISP tests |

| **14** | Security verification        | Verify Snooping, DAI, STP and Port Security           |

| **15** | Evidence/screenshots         | Capture the required proof for your portfolio         |

| **16** | Documentation                | Write the project report/readme                       |

| **17** | GitHub                       | Add the final project to your clean SOC portfolio     |
